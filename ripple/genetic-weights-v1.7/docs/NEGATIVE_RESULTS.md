# Retained negative and conditional results

1. **Phase rotations are not a universal enhancement.** Complex-coupled evidence may corrupt independent bit channels. Phase plus and phase minus scored worse than the fixed reference on the new seeds under this optical generator. No quantum advantage is claimed.
2. **Ternary quantization discarded useful magnitude.** Sign-only LLR transformation performed poorly when photon count changes. This is a legitimate failure case, retained.
3. **Program-family priors added no observed benefit to the selected genotype.** Removing the entire family-prior vector gave the same reserved performance; selected vector was zero. Calling this successful library learning would be false.
4. **Selected mode was simple temperature scaling.** The development-selected gene used cold LLR scaling (0.62), a classical technique; it was not a novel physical or neural formula.
5. **Coverage and precision conflict.** The highest precision training champion supported fewer tasks than the development-selected gene. Report both.
6. **The fixed control and v1.6 comparator are different methods.** The v1.7 fixed control applies a simplified single-pass likelihood and decision gate; v1.6 uses its prior 7/3 fit/confirmation gate. The fair genetic ablation is against the v1.7 fixed control, not an assertion that all apparent difference from v1.6 comes from genes.
7. **New expressibility was deliberately tested on compositions.** The favorable 108-case composition study contains eight families specifically constructed from allowed pairs. That is a positive control, not arbitrary unfamiliar program discovery.
8. **The unknown permutation has no general guaranteed answer** from 10 observed inputs, and can be falsely accepted if extra function candidates happen to fit. Never claim complete cryptanalysis.
9. **Serial and Ripple-gated inference tie.** For all 108 composition tasks and all 180 v1.6 fresh-reference tasks, paired solutions are identical. The original LIF adds event telemetry and scheduling but not reasoning quality.
10. **Optical mismatches remain serious.** The simulated phase-shifted condition frequently induces abstention or error even for expanded grammar. Sensor calibration and independent real measurements are missing.
11. **No globally optimal genotype:** 256 mutation evaluations and seven evidence representations are a bounded exploration; neither general intelligence nor all possible weights are exhausted.
12. **Source preservation matters:** Script copies preserve original source. The new proposed algorithms are isolated and do not retroactively modify prior Ripple releases.
