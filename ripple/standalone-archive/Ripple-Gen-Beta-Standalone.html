Design advancements: strengths and boundaries

Final Beta dependency map

synthetic RGB / future validated sensor adapter │ ▼ [Optional v0.6 photoreceptor] → [LOCKED v0.1 Ripple Neuron] │ │ ├─ optically compressed RGB ├─ pulses & adaptive gate │ ▼ └──────────────────► [v0.7 Quad state encoder] │ (TELEMETRY ONLY) [synthetic 2D grid, occlusion, numerical occupancy] │ ▼ [allowlisted SCAN/MOVE/SHARE/CLONE/WAIT] │ ▼ [local memory + bounded lineage] │ ▼ [replay, traces, holdout trials, guardrails]

Spatial diffusion, sensor input, and colony behavior are simulated. The real physical sensor bridge is a separate future evidence gate; raw hardware telemetry never enters the Beta simulation disguised as measured input.

Evidence categories

Source verified

Original LIF source byte-for-byte preserved, v0.6 photoreceptor original archived, v0.7 quaternary source preserved.

Numerically verified

Conservation, bounded evolution, deterministic replay, 2-bit packing and LIF brightness-step regression.

Synthetic comparisons

300 policy runs and 420 ablation runs over fixed worlds. Not hardware measurements or general-purpose intelligence tests.

Not demonstrated

Physical camera calibration, mass density, motor control, robot intelligence, GPU acceleration, unseen real-world navigation, self-authored code.

Bounded execution contract

Allowed actions: SCAN, MOVE, SHARE, CLONE, WAIT. No eval, arbitrary code, network calls, filesystem writes by digital agents, external API permissions, motor commands or cloud spending. Maximum 16 agents, 1,200 ticks, eight decision rules, 1,024 remembered cells per agent.

This lab is not an artificial intelligence model. Its programs are deterministic or seeded procedures for transparent research.
