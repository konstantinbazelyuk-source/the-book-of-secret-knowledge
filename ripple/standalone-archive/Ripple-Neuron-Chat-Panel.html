How the neuron works
D = 2.0R + 1.2G − 1.4B τᵥ du/dt = −u + D When u ≥ θ: emit event, reset, refractory hold Feedback changes θ toward target event rate

The same original Ripple Neuron v0.1 equations and event-crossing algorithm drive this panel. A camera measures processed RGB pixel intensities; the model computes neuron-like events.

Evidence boundaries

The numerical neuron is operational. The camera interface is a phone-based input adapter, not a replacement for the AS7341's eight spectral bands. Camera input depends on embedding permissions, exposure, white balance, and calibration. The physical optoelectronic circuit has not been built or verified.
