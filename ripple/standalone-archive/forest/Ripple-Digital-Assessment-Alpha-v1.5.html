Evidence boundaries

This system performs bounded, document-level supervised classification, lexical retrieval, and evidence-path tracing. It does not train the Daughter Δ³ optical neuron to understand human language, update the original forest movement code, or independently produce trustworthy answers.

Four symbols −1, −0, 0, 1 are reused as a two-symbol document address, with a different explicit meaning than the forest's learned movement message. Each document is assigned an index 0–7 and the address is reversible.

Results count question-to-document correctness. They do not evaluate the truth of a user-provided answer, fine-grained passage relevance, new domains, general intelligence, or physical sensor input.

Controls: no external calls, no file writes from the app, no arbitrary script execution, no autonomous posting, no uncited free-form claims, size-limited queries, optional user-initiated feedback, explicit export, and immutable evidence. Training labels are withheld from runtime inference. Learnable weights can be reset.

The source corpus contains 8 documents from 3 existing Ripple families. All original parent archives remain untouched. No monochrome, camera, or metaphysical study is active.
