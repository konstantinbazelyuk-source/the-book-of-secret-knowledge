What this phone version actually measures

Android camera frames supply average red/green/blue image pixel values in a small central target area. They are not eight AS7341 spectral measurements, optical field measurements, or absolute irradiance.

The quick camera mode scales camera RGB (0–255) to 0–1, so its behavior changes with lighting, camera exposure, white balance, and surface reflectance.

The optional calibration estimates three source amplitudes using a 3 × 3 matrix built from darkness and separate red, green, and blue reference frames. That is a simplified phone-camera approximation of the original multi-band reference decoding, not identical performance.

D = 2.0R + 1.2G − 1.4B τᵥ du/dt = −u + D if u ≥ θ: emit event, reset, refractory pause θ adapts toward a target firing rate

The neuron model code and the 120-second comparison are preserved from Ripple Neuron v0.1. Camera capture is the new input adapter; model outputs are simulated neural events computed from actual camera measurements.

Testing limitations

Camera access requires user permission and a compatible secure browser context. For repeatable comparisons, use a stationary phone, stable controlled light and avoid saturated pictures. Browser camera settings cannot reliably lock exposure/white balance across Android devices; a native Camera2 adaptation may improve control.

Camera input and model execution stop when the page is suspended or backgrounded. No continuous background sensing, autonomous decision-making, cloud communication or robot control is claimed.

Privacy: captured video is processed locally in memory, not recorded or uploaded. CSV export contains optical channel summaries and neuron states, not images. The app makes no network requests for inference or camera data.
