Software-research boundaries

Each strain is catalogued by exact archive bytes, provenance, source role, candidate function descriptors and hybrid parent links. Proposals cannot execute external code; the tested interoperability chain imports only explicitly pinned trusted modules.

Never automatic: arbitrary JavaScript execution, account access, self-updating core source, physical hardware control, blockchain mining, or cloud spending.

Deployment readiness: a manually invoked GitHub Actions workflow is included in the package. This page is an offline viewer, not a continually running cloud agent.

Next scientific gate

A true cross-research agent would need permission-scoped retrieval, independent replication of findings, calibrated real input, validated models of change, uncertainty-aware decisions and longitudinal generalization tests. Those are requirements, not achieved intelligence.

For now the seedbank provides a stable base for comparing and preserving future variants without overruling proven work.
