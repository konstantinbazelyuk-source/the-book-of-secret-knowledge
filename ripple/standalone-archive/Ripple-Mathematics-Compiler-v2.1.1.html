Registered formula

I = I₀ e−μL

The attenuation coefficient μ uses m⁻¹ and optical path L uses metres; their product μL is dimensionless. Input and output intensities use the same units.

A collimated, narrowband beam passing through a homogeneous, non-scattering medium is assumed. Camera RGB and scanned-digit pixels are not calibrated photon intensities.

Compiler boundaries

Only allowlisted formula IDs and operations are accepted. Mathematical coefficients must be finite, μ ≥ 0, L ≥ 0, and μL ≤ 100 as a numerical guard. Inverse calculations require an independent nonzero reference intensity and a known nonzero coefficient or path. No browser camera, sensors, network requests, dynamic scripts, or autonomous code execution are used.

Evidence and references

IUPAC Gold Book, Beer–Lambert law (B00626) and transmittance (T06484). The previous Ripple Gen Beta v2.1 implementation remains unchanged and is used as the underlying calculation reference. These numbers are model calculations; no material or atmospheric density is inferred.
