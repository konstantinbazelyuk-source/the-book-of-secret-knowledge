1. Actual held-out recognition

RECORDED

8×8 digit images contain scanner-derived pixel occupancy counts (0–16), not calibrated spectral measurements. All learned classifiers used labels only outside the held-out set.

A hybrid with additional Ripple features is not necessarily better. The native input-pixel model matched the combined model on this test; the specialized Ripple features alone were less accurate.

3. Light attenuation: mathematical intervention

SIMULATED OVER RECORDED IMAGES

The starting images were recorded observations; each reduced-light case is a synthetic transformation with fixed attenuation coefficient 0.35. The digit labels remain ground truth. The light-augmented classifier was trained on simulated paths 0–3; path 4 was not in its augmentation set.

Known-law oracle is not a blind sensor: it is supplied the exact coefficient and path used to generate the synthetic attenuation, and therefore reverses the ideal transformation algebraically.

Provenance and reproducibility

Data: scikit-learn Optical Recognition of Handwritten Digits, sourced from the UCI dataset and preprocessed from handwritten forms using NIST methods. Tests use a predeclared stratified split; the original source contains no writer IDs for writer-disjoint testing.
