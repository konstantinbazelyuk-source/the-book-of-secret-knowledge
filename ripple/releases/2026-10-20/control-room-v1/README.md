Control Room is a responsive local web UI served by a Python backend and connected to the Heterogeneous Mathematical Fusion v1 execution engine. It provides RGB input controls, steps, waveform batches, continuous/pause processing, typed subsystem switches, causal event tracking, XYZ training, replay/session data import/export and recovery checkpoints.
