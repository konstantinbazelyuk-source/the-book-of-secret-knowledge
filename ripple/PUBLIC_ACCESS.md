# Public access to Ripple

Canonical source: https://github.com/konstantinbazelyuk-source/the-book-of-secret-knowledge/tree/master/ripple

Browser-site files: https://github.com/konstantinbazelyuk-source/the-book-of-secret-knowledge/tree/master/docs

GitHub Pages (requires activation): https://konstantinbazelyuk-source.github.io/the-book-of-secret-knowledge/

To activate the public webpage: Repository Settings > Pages > Build and deployment > Deploy from a branch > master > /docs > Save. GitHub Pages publishing can take several minutes. Until a live URL is separately verified, the GitHub source files and repository download remain the verified public-access route.

This published research includes a live numerical simulation of the original Ripple neuron in JavaScript and five preserved Alpha research-explorer HTML files: genetic weights v1.7, wave/photon double slit v1.4, code-reasoning colony v1.5, open-grammar colony v1.6, hybrid gene-lineage research v1.1.

For installation of the actual desktop runtime see ripple/native-alpha-v2.0/README.md. The laptop software requires Python and Node.js. It is not a compiled Windows installer.

No paid hosting or external AI service was activated. The laboratories use calculated/simulated data and must not be advertised as measurements of physical hardware or independent intelligence. Original source authorship and license notices remain unchanged.
