Science: conditional photon channel

For each transmitted bit, the two-slit model generates a different photon-arrival distribution. Photon counts enter a log-likelihood decoder; actual electric or magnetic field amplitudes are not measured.

Bright line: coherent bit = 1Dim line: incoherent bit = 0
A real optical link would require a physical coherence modulator, calibrated detectors and timing. This laboratory uses generated observations only.
