03 / reproducibility

Download, verify, reproduce

The canonical source code is maintained publicly in Secret Book of Knowledge. The Dell runtime has been tested in a Linux development environment, but Windows-specific operation and performance on the owner's Dell laptop remain unverified.

git clone https://github.com/konstantinbazelyuk-source/the-book-of-secret-knowledge.git
cd the-book-of-secret-knowledge/ripple/native-alpha-v2.0
# Windows PowerShell: .\bin\Setup-Dell.ps1
# Windows CMD/PowerShell: .\bin\Start-Ripple-Windows.cmd
