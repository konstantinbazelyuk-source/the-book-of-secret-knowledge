# Kokoro actual source-model transfer: browser test v0.2

This isolated workbench uses the actual native Kokoro v0.3 source, SHA256 be9cb6b2575334ff912f45a9ff226a552f7216d2b1d7707ba830f8867690ce93. Blender is an authoring/conversion step, not a playback dependency. The original .blend and existing studio remain unchanged.

Run: cd viewer; npm ci --ignore-scripts; node server.cjs; open http://127.0.0.1:8863. The hosted control-review.html is a single-page control probe using pinned Three.js 0.180.0 and integrity-checked hosted model/control bytes. It is not the full Kokoro identity, memory or VTK vision application. Controls run the faithfully translated original three-motor numerical simulation plus manual facial settings. No saved animation clip is played in the live viewer.

The recovered prior complete studio package is separately preserved: https://ripple-neuron-phone.floot.app/_cdn/static/8a27df96-1fb9-4f0c-bc5e-a6634f8659e4-Kokoro_Portable_Runtime_Recovered_v0_1.zip ; SHA256 87903d56c532a84d165396dc9b59b9f2e664f3201e0faecefe72fe4cad651385. Its GitHub CI result is archived evidence, not a fresh full-studio rerun in this cycle. Do not replace that complete studio with this probe.

Fresh checks: 7 control response tests, 4 motor port tests, 500-step independent Python comparison, 12 browser checks including bad/stale input rejection, 40 newly computed canvas frames, model hash verification and phone-sized layout. These prove bounded software control and rendering, not generalized intelligence. The 40-frame GIF is recorded evidence only; use the interactive page to change controls live.

Limits: 411 exported skin joints are not 411 independent controller channels. Eight supported inputs: head/right arm/right forearm, eyelids, jaw, gaze X/Y, original pupil control. All original Blender constraints are NOT ported. Coupled arm interpolation was improved with 546 sampled source evaluations; combined face controls still have measured residual differences. Blender non-armature modifiers are baked once and runtime deformation is not proved identical to every native pose. The original neutral material bakes and KokoroFaceTint source color layer are reused. Lambert compatibility shading does not preserve native refraction/subsurface look. CPU skinning fallback is tested; direct GPU skin/morph path failed in this ARM software renderer and is not claimed passing. Final recorded mean update/draw ~108 ms in one run, not a performance guarantee or phone benchmark. Simulated time can run slower than wall time. Optical eye calibration, original FieldSphere bus, VTK visual feedback and target-platform fidelity remain OPEN.
